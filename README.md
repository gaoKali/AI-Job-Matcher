# 向前 · 简历分析与 AI 简历优化

打开 http://127.0.0.1:4173/，或双击本目录“启动网页.cmd”。

上传 PDF/DOCX 或粘贴简历 → 进入简历分析 → 前往 AI 简历优化 → 填目标岗位、粘贴 JD → 开始优化简历。优化重点和额外要求可选。

可以查看原文/优化后/原因、JD匹配与缺口，复制完整优化文本，调整要求再主动优化。每次优化一次 Qwen 请求，不调用岗位搜索。请核对事实后使用。

简历和 JD 只保留在当前网页内存，文本会发送给现有 AI 服务处理。密钥仍只在原 Cloudflare Worker；无需新账号、密钥或代码修改。刷新会清空本次材料。

最新实现与验证见 [简历优化](docs/RESUME_OPTIMIZATION.md)。旧岗位搜索代码保留但正常流程已关闭。
