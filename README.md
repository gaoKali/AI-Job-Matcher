## 打开网页

双击“启动网页.cmd”，或打开 http://127.0.0.1:4173/ 。上传或粘贴简历 → 进入简历分析 → 填写求职条件 → 搜索匹配岗位。无需写代码、注册或提供密钥。刷新网页获取最新脚本。

正常流程只显示真实岗位，来自Greenhouse、Lever、Ashby。公开源以国际科技公司为主，中国本地覆盖有限；无结果可放宽城市或岗位关键词。每次最多10个相关岗位一次AI匹配，可按分数、公司、地区、来源筛选，点击查看真实岗位打开公司招聘页。分数不是录用概率，签证和未描述的能力需核对。

## 隐私与成本

原始PDF/DOCX仅在浏览器读取，简历文本和分析摘要经现有Worker发给AI；不会发给招聘网站。本站不永久保存简历，不使用数据库；刷新或重新上传清除内存。AI服务处理以供应商政策为准。不要补写不真实的经历、技能或成果。

单份简历最多12000字符，每轮岗位匹配最多10个、一次批量模型调用，无自动格式修复重试或后台任务。公开岗位读取不使用AI，基本超时/实例限流保护已加入，免费额度仍以平台实际额度为准。AI失败不冒充匹配结果，真实岗位标记暂未评分并允许手动重试。
