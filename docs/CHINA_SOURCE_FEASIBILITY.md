# 中国大陆岗位来源第一阶段验证

日期：2026-10-05。测试输入：岗位「用户运营」、城市「北京」。本阶段只验证，不替换现有网页搜岗功能。

## 正式来源优先级

第一优先级：BOSS直聘、猎聘、智联招聘、企业公开招聘官网，四者同级。
第二梯队：前程无忧、拉勾、脉脉招聘、牛客招聘及其他公开国内渠道，仅第一梯队数量不足时补充。
第三梯队：Greenhouse、Lever、Ashby，仅作为补充。

## 环境与证据边界

本地 Node 原生 fetch，无 Cookie、无登录、无代理、无伪装 User-Agent。仅读取公开 HTML，没有探测或逆向私有接口。公开 HTML 内的职位标签和公开导航链接可以读取；不读取 JS 包中的内部接口。
Cloudflare 的一次性固定来源验证已部署，随后直接访问失败；Wrangler 官方远程预览启动成功，但通过预览请求也超时。**没有取得任何云端来源验证结果**，不得把本地结果当成 Worker 成功。工具浏览器还返回 ERR_BLOCKED_BY_CLIENT，这不是招聘网站的 403 或验证码证据。
测试不涉及简历、Qwen、API Key 或 API Base URL。临时生产诊断路由已撤回，生产 Worker 保留原来的简历分析、岗位接口。

智联真实详情页验证：
https://www.zhaopin.com/jobdetail/CC892738830J41035769802.htm
本地 200，真实标题「学管班主任（用户运营专员）」、公司「北京拓词智能科技有限公司」，正文可以读取，没有观察到强制登录或验证码。HTML 有登录入口不等于强制登录。详情页薪资被掩码，不能直接用此字段推断真实薪资。

神策官方原始页面：
https://www.sensorsdata.cn/about/joinus.html

## directFetchSupported 标记

此处是本地 HTML 直接提取能力：BOSS false，猎聘 false，智联 true（仅 HTML 候选，不代表可靠搜索）；企业逐站标记：神策 true，其他已测目标 false。所有来源 workerDirectFetchSupported 均为 null（未验证），上线门槛未通过。正常跳转不单独认定为访问限制；目标空壳才是提取失败的原因。

## 后续企业官网设计（待确认后开发）

独立来源注册表，每家公司保存真实官方入口、官网认定依据、公开读取方式、能力状态、最近验证时间和适配器名称；允许逐步增加公司，不设固定 10 家上限。先从可直接读正文的官网扩展，复杂官网需公开文档接口或后续允许的其他方案；不逆向私有 API、不绕过限制。
岗位/城市参数由用户输入生成，HTML 岗位按实际标题、实际地点和用户条件筛选。现有测试生成器独立于 UI，已包含北京/上海/深圳参数映射；这只是测试工具，不是完整城市搜索实现。职位字段统一 title/company/location/salary/experience/education/description/url/source/publishedAt，缺失填「未公开」，不由 AI 补猜。

## 上线结论

现在不能宣称任何来源已经通过生产 Worker 验证、可以直接上线。
优先继续智联公开页面的相关性验证与可直接读取的企业官网；BOSS/猎聘以及复杂企业官网需后续合法公开接入方案。不需要 Python；Python 也不能解决空壳、登录或反爬限制。本次未使用付费搜索服务，此轮验证也不需要购买；未来全面覆盖国内岗位尚未证实能够仅靠这些免费来源实现。
