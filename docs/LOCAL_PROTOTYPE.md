# 第 2 步：本地模拟版交付与验证

日期：2026-10-04。状态：本地模拟流程验证完成；未接入外部服务。

## 实现范围

原生 HTML/CSS/JavaScript，零第三方运行依赖，无 React/Vue/Next.js、数据库或登录。原 Skill 压缩包保持原样；三份规划文档已复制至正式项目，并在产品需求与任务清单顶部注明本轮范围优先于旧 Next.js 路线。

提供文件选择、拖放界面、PDF/DOCX 元信息校验、文本粘贴、示例简历、完整模拟分析、七项求职需求、7 个模拟岗位、分数排序与筛选、空结果提示、详情弹窗、重新搜索与清空重传。所有分析和岗位明确标为虚构演示。

真实文件解析、AI 分析、真实岗位搜索与原始申请链接均未实现。自由文本条件只展示，不假装已自动解读或执行。未来接入位置在 js/providers.js 的 resumeParser、analysisProvider、jobProvider，密钥应由后续独立服务端管理。

## 自动检查

- js/app.js、js/providers.js、server.cjs 的 Node 语法检查通过。
- 6 项 Node 离线测试通过：文件类型/大小/空文件校验、Mock 与真实输入隔离、岗位数量和分数/来源边界、排序筛选、需求评分变化及数据独立性、解析待接入状态。
- 本地静态服务仅绑定 127.0.0.1，限定可访问文件，不支持上传或其他写入请求，禁止页面网络连接。
