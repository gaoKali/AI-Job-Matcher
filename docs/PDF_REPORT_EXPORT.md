## 用户操作

在 Chrome 或 Edge 打开 http://127.0.0.1:4173/，Ctrl+F5 刷新。完成优化后，结果顶部显示“下载 PDF 报告”。点击打开系统打印窗口，选择“另存为 PDF”或“Microsoft Print to PDF”，纸张 A4。若希望不显示浏览器自带的地址/日期页眉页脚，可在打印设置中关闭页眉和页脚。手机使用支持打印的浏览器，保存入口由系统提供。

## 实现

js/report-print.js 用已经生成的优化结果构建独立报告，不抓网页截图。print-report.css 单独定义 A4、中文字体、页边距、深色正文和少量绿色。打印时只显示 pdf-report，其余网页导航、表单、控件和装饰隐藏。屏幕上的折叠状态和滚动高度不影响导出。
报告包括岗位、生成时间、原始匹配度、JD与关键词、全部优势/差距、优化重点、真实简介/技能、经历和项目对照及原因、事实提醒、补充建议/问题、完整稿及免责声明。无项目不显示项目区，无可确认简介不伪造。
较短对照卡保持完整；长卡允许自然分页，使用重复表头标明公司与原文/优化后。完整稿从独立新页开始，全文没有高度或滚动限制。中文使用本机字体，无远程字体依赖。
打印不修改原结果，标题临时作为文件名候选，afterprint、打印媒体退出、窗口焦点恢复时恢复标题及下载按钮。浏览器不支持时显示使用打印/分享菜单的提示。重新上传/重新优化清空旧的打印树。所有文本转义，不执行结果中的HTML。
