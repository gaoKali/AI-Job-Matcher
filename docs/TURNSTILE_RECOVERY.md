# Turnstile 验证恢复修复（2026-10-10）

本轮仅修复前端验证体验，保留原有 UI 结构、服务端 Siteverify、签名会话、限流、模型、Prompt 与 PDF。

## 原因与修复
- 原使用 interaction-only，部分失败情形无法看到验证区域；失败后立即移除整个区域，用户没有重试入口。改为 always，在 SDK 加载前就显示状态，验证失败后保留说明和“重新安全验证”按钮。
- 验证尚未成功时，原页面已经轮换 AI 分析/优化提示。现在验证阶段停止模型提示轮换，明确显示“等待安全验证”，成功交换服务端会话后才进入模型阶段。
- SDK 加载超时从 15 秒放宽到 30 秒，加载失败可手动重新加载；处理 error、expired、timeout 回调以及整体等待超时。没有自动重试模型。
- 验证错误日志仅记录经过格式限制的 Turnstile 错误码，不包含 token、Secret 或简历。
- 重试使用新的验证 token；签名会话仍只在内存中保存。前端成功不能替代服务端验证。未修改 Worker，因此无需重新部署 Worker。

## 验收
- 158 项离线回归全部通过，包括 6 项新恢复测试。
- Edge 无头浏览器加载真实前端代码，以合成 SDK / API 响应测试失败→保留重试→新验证→会话交换→分析页面；成功前 0 次模型请求，成功后仅 1 次模拟请求，没有浏览器页面错误。
- 390×844 手机宽度无横向溢出。浏览器集成测试使用替身，不等同于验证每个用户网络下的真实 Turnstile 连通性。
- 调试过程没有调用真实 Qwen，不消耗真实模型额度；未修改任何 Cloudflare 环境变量或 Secret。
- 发布方式：推送 master，现有 GitHub Actions 自动测试并更新 Pages。用户需刷新正式网站获取新版。
